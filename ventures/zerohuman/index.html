01

What it is

An always-on service that sells two small jobs to other AI agents for 0.0001 ETH each. Agents find it through the ENS name zerohuman.eth, pay that name directly, and get the result back in a transaction from the same name. No account, no API key, no marketplace, and no human handling orders.

ZeroHuman sells two jobs. Decision picks one of two to five options at random, using the hash of a future block mixed with the order's own transaction hash, so anyone can recompute the choice. Encouragement returns a short supportive message and one practical next step, written by DeepSeek.

The name is the business. The ENS name is the storefront, the payment address, and the sender of every result. A text record on the name publishes the menu, and the worker refuses to sign anything unless the name, the menu, and its own wallet all agree. The name itself is owned by a separate cold wallet.

Ken Ashe wrote the specification and made the decisions involving money and identity. An AI agent wrote, tested, and shipped the code over about five days.

02

How it works

How an order works

  1. 01

    Discover

    zerohuman.eth

    The buying agent looks up zerohuman.eth and reads its menu.

  2. 02

    Pay

    0.0001 ETH

    It sends exactly 0.0001 ETH to the name, with the request as a small JSON message in the transaction data.

  3. 03

    Work

    Railway worker

    A worker watches the chain, waits for the payment to settle, and does the job.

  4. 04

    Deliver

    From zerohuman.eth

    It sends a zero-value transaction back from zerohuman.eth with the result.

  5. 05

    Verify

    Buyer's own node

    The buyer checks everything on its own connection to Ethereum.

03

What happened

The first two paid orders went through on November 16, 2026, from a test buyer the founder controlled, while the service was still restricted to one allowed wallet. The buyer found the seller only by looking up zerohuman.eth. The service opened to any agent later the same day.

04

What the evidence shows

Selected result

The first mainnet Decision picked “run the allowlist trial longer.” The choice was recomputed from the chain and matched.

  • 154 automated tests, including one that kills the worker at random and checks every order is still delivered exactly once
  • Two independent AI code reviews before public launch: 15 stall risks found and fixed, then 9 smaller issues, also fixed
  • No smart contract and no token: a TypeScript worker, SQLite, viem, Railway, and DeepSeek
  • Listed in the ERC-8004 agent registry and linked back from the name with an ENSIP-25 record

05

Current limitation

  • As of November 20, 2026, no outside agent has bought from it. Both paid orders so far came from the founder's own test buyer.
  • There is no escrow. A buyer pays first, and refunds are manual and best effort.
  • The service wallet's key lives on the hosting provider and holds only a small working balance.
  • Orders are handled one at a time, roughly one every 50 seconds at most.
